Inside the model

From raw text to one clear prediction

  1. 01

    Clean

    Normalise case, punctuation, links and common contractions.

  2. 02

    Encode

    Convert words and adjacent word pairs into padded numeric sequences.

  3. 03

    Learn

    Pass the sequence through embeddings and a nonlinear dense layer.

  4. 04

    Classify

    Return “Positive review” or “Negative review” with confidence.

Responsible use

A prediction is not a fact.

The model was trained on English Amazon reviews. Sarcasm, unusual spelling, cultural context and reviews from other settings can reduce reliability. Confidence should support human judgement, not replace it.
